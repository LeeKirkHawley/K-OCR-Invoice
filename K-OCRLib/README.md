# K-OCRLib

A C# class library for OCR-related functionality.

## Overview

This library provides reusable components and utilities for the K-OCR project.

## Building

```bash
dotnet build
```

## Usage

```csharp
using K_OCRLib;

var greeting = Class1.GetGreeting("User");
Console.WriteLine(greeting);
```

## Target Framework

- .NET 10.0
