# SEO Implementation Plan

## Goal
Improve organic visibility by fixing the highest-impact technical and on-page SEO issues first, then reinforcing content quality and measurement.

## Steps

1. **Lock down indexability and crawlability**
   - Ensure important pages are indexable.
   - Add or verify `robots.txt` and `sitemap.xml`.
   - Fix broken links, redirect chains, duplicate routes, and canonical issues.
   - Make sure every important page has a single preferred URL.

2. **Improve page metadata and headings**
   - Give each page a unique, intent-focused `<title>`.
   - Write a compelling `meta description` for major pages.
   - Use one clear `H1` per page and logical `H2/H3` structure.
   - Remove thin or repetitive headings that dilute topic focus.

3. **Strengthen content relevance**
   - Map each page to a primary search intent.
   - Expand pages that target important queries with direct answers, examples, and FAQs.
   - Consolidate overlapping pages that compete for the same keyword.
   - Add internal links to and from related pages using descriptive anchor text.

4. **Add structured data where it fits**
   - Use schema for articles, products, organization info, breadcrumbs, and FAQs if applicable.
   - Validate markup and keep it aligned with visible page content.

5. **Improve performance and mobile UX**
   - Reduce page weight, script bloat, and render-blocking assets.
   - Optimize images, fonts, and caching.
   - Fix Core Web Vitals issues, especially LCP, INP, and CLS.
   - Verify mobile layouts and tap targets.

6. **Set up measurement and iteration**
   - Connect analytics and search console data.
   - Track impressions, clicks, rankings, crawl errors, and index coverage.
   - Review pages with high impressions but low CTR and rewrite titles/descriptions.
   - Revisit pages regularly to refresh outdated content.

## Definition of done
- Key pages are indexable and discoverable.
- Metadata is unique and aligned to search intent.
- Duplicate and thin content is reduced.
- Structured data is valid where used.
- Performance and mobile experience are acceptable.
- Search metrics are monitored and reviewed regularly.
